## Beats and templates
Purpose: the story's building blocks, arranged (never judged) by a structure template.

Features:
- [MVP] Beat: title, description in the user's words, characters involved, links to screenplay blocks and storyboard frames.
- [MVP] Beat cards: paper-coloured index cards on the dark frame; a muted colour band for the act/sequence; icons showing whether script text and frames exist.
- [MVP] Edit, drag to reorder (long-press), split and merge beats.
- [MVP] Add beats directly or through proposals.
- [MVP] Template slots: beats placed into ordered slots; one slot holds many beats; empty slots stay empty with no warnings.
- [MVP] No-template mode: a plain ordered list of beats.
- [MVP] Template switch: the AI proposes where each beat goes in the new template; the user confirms or drags to adjust; beats are never deleted.
- [MVP] Template library: built-ins from library R1.
- [MVP] Create and edit templates by hand.
- [MVP] Fetch a new template from the web ("get me the Kishōtenketsu structure"), previewed before saving (see area 10, fetch and convert).

Notes:
- Template format: name, description, source link, suitable project types, ordered slots (name, description, optional runtime proportion).
- Auto-placement of new beats only if that AI permission is on.
- Spec §9.
