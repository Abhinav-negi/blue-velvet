## Characters
Purpose: reusable character sheets shared across all stories.

Features:
- [MVP] Character sheet: name, age, role in story, appearance, background, personality traits, habits, wants/needs/fears, notes.
- [MVP] "Appears in": list of beats, filled in automatically.
- [MVP] Create by hand.
- [MVP] Extracted from input by the AI (if permitted), always arriving inside a proposal.
- [MVP] Promote a Character item from the Void.
- [MVP] Global character pool across the app.
- [MVP] Import into a project from the pool or from another project; linked by default (edits flow both ways).
- [MVP] Fork: make a project-local copy that evolves separately.
- [MVP] Characters list per project (Characters tab).

Notes:
- The AI only fills fields with what the user actually said.
- Spec §11; assumption A5 accepted (D-13).
