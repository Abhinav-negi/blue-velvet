## Script
Purpose: write the screenplay (films) or Say/Show script (YouTube, Shorts) for each beat.

Features:
- [MVP] Screenplay editor on a paper page in Courier Prime, with correct margins scaled to the screen.
- [MVP] Elements: scene heading, action, character, dialogue, parenthetical, transition (rules from library R3).
- [MVP] Enter/Tab switches element type in the standard order (scene heading → action → character → dialogue → parenthetical).
- [MVP] Element-type chip in the left margin; tap to change.
- [MVP] No toolbar while writing; formatting options in a bottom sheet on request.
- [MVP] Say/Show script: two columns per beat or segment. Say = spoken lines (written by the user); Show = A-roll, B-roll, on-screen text, graphics notes.
- [MVP] Scaffold on new beat (if permitted): a skeleton built only from facts the user gave, e.g. a scene heading for a location they named and an action line naming who is present.
- [MVP] Structure suggestions on request only ("other ways to open this beat?"), clearly marked as suggestions.
- [MVP] Swipe right from a beat's script to its storyboard; a two-dot indicator shows which side is showing.

Notes:
- The AI never writes dialogue (spec §10.1, §15.3).
- Proposals only append to written screenplay text (D-18).
- Spec §10.1, §10.2, §6.1.
