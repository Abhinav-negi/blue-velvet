## Export
Purpose: get work out of the app in standard formats.

Features:
- [MVP] Screenplay → PDF in standard industry formatting (Courier Prime 12 pt, rules from library R3).
- [MVP] Screenplay → Fountain plain text (syntax from library R3).
- [MVP] Storyboard → PDF: frames in a grid with shot details and notes, grouped by beat.
- [MVP] Script (YouTube/Shorts) → PDF in the Say/Show two-column layout.
- [MVP] Story bible → PDF: project summary plus character sheets.
- [MVP] Share or save the exported file via the Android share sheet.

Notes:
- Fonts are bundled, so exports look the same offline.
- Spec §16.2. Decision: D-10.
