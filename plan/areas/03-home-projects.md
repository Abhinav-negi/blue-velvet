## Home and projects
Purpose: see all projects, turn ideas into projects, and give each project a "repository" home page.

Features:
- [MVP] Home: project list plus entry to the Infinite Void; global badge for pending proposals across all projects.
- [MVP] Pre-project review: clean summary of a story idea; edit, ask for changes, or add more input to it.
- [MVP] Approve (thumbs up) → choose project type (short film, long film, YouTube video, short) → choose template (2–4 suitable options, the type's default first).
- [MVP] Project creation: generate summary, characters found in the user's words, beats placed in the template, and screenplay/script scaffolds, each only if that AI permission is on. Storyboards always start empty.
- [MVP] Characters-first start: empty project with a working title only.
- [MVP] Project shell: top tab row (Overview, Characters, Beats, Script, Board, Settings) on phones, left rail on tablets.
- [MVP] Overview: summary (README), pending proposals, recent history.
- [MVP] Project-type defaults (length, template, writing section, aspect ratio, type-specific fields) loaded from library R4.
- [MVP] Type-specific fields: YouTube (A-roll/B-roll per segment, title ideas, thumbnail ideas); Shorts (hook text for the first ~2 s, caption, on-screen text).
- [MVP] Sample project on first launch (S5): the playground/watchman story from spec §19, fully built out; deletable.
