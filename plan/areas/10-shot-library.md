## Shot library
Purpose: a global, growing reference of shot types with pictures, usable from any storyboard frame. Also home to the generic "fetch and convert" flow.

Features:
- [MVP] Entry: name, category (shot size, angle, movement, composition, lens, lighting), description, when to use, emotional/narrative effect, reference images, source links, tags.
- [MVP] Built-in starter set from library R2, with free-license reference images where available.
- [MVP] Browse by category and search.
- [MVP] Attach an entry to a storyboard frame; its reference images appear beside the drawing.
- [MVP] Add your own images or sketches to any entry.
- [MVP] Ask for options ("what shots work for a tense standoff?"): answers come from library entries plus fetched ones.
- [MVP] Shot suggestions for frames (if that AI permission is on).
- [MVP] Fetch and convert: the AI searches the web (Gemini Search grounding), converts the result into a template or shot entry, shows a preview with sources, and saves to the library only on approval. If a result doesn't fit a known format, it says so instead of inventing one.

Notes:
- Images fetched from the web stay in the user's personal library. Built-in images are free-license only, with license and author recorded (D-15).
- Free-tier limits for Search grounding are unverified (OPEN-QUESTIONS).
- Spec §13, §15.4.
